# Rule-Based AI Chatbot 🤖 " AI"

## DecodeLabs Artificial Intelligence - Project 1 Intern

This project is a  Rule-Based AI chatbot developed using Python.

## Project Objective

The objective is to create a chatbot that responds to predefined user inputs using rule-based decision-making and basic control-flow concepts.
# gained skills:-

-> Using if, elif, and else statements.
-> Working with Python dictionaries.
-> Creating and managing predefined intents.
-> Using while loops for continuous interaction.

-> Processing and sanitizing user input.
-> Handling unknown or unexpected inputs.
-> Implementing exit conditions.

## Features

- Handles greetings
- Handles predefined user questions
- Uses a dictionary-based knowledge base
- Supports multiple predefined intents
- Uses if-else decision-making
- Uses a continuous while loop
- Sanitizes user input using lowercase conversion and whitespace removal
- Provides a fallback response for unknown inputs
- Supports exit commands

## Technologies Used

- Python 3
- Dictionaries
- Conditional statements
- While loop
- Functions
- String methods
